# Trivia Quiz

A trivia quiz built with HTML, CSS, and JavaScript using the Open Trivia Database API.

## Features
- Custom questions, categories, and difficulty.
- Multiple-choice and true/false questions.
- Optional timer.
- Light and dark mode.
- Sound effects and score tracking.
- Save progress using Local Storage.

## How to Use
1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Install the **Live Server** extension.
4. Open `index.html` and click **Go Live**.

## Project Structure
- `index.html` – HTML structure.
- `style.css` – Styling.
- `script.js` – Quiz functionality.
- `dropdown.js` categories Drop Down from api
- `image/` – Images and sounds.
